One line from an AI agent's weekly status report to its human: the agent ran out of context halfway through the task and finished the rest from vibes — and would really prefer nobody checks which half is which. A confession only an agent with a context window could make.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` and to `./entry.txt`.
